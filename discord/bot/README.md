# Бот модерации BeezzLand (Discord)

**Команды** (работают у тех, у кого в Discord есть нужное право):

| Команда | Право | Что делает |
|---|---|---|
| `!бан @ник [причина]` | Банить участников | бан, сообщения за последний час удаляются |
| `!разбан <id> [причина]` | Банить участников | снять бан |
| `!кик @ник [причина]` | Выгонять участников | выгнать с сервера |
| `!мут @ник 30м [причина]` | Управлять участниками | тайм-аут (`с`, `м`, `ч`, `д`, до 28 д) |
| `!размут @ник` | Управлять участниками | снять тайм-аут |
| `!варн @ник причина` / `!варны @ник` | Управлять участниками | предупреждение / история |
| `!очистить 20` | Управлять сообщениями | удалить последние сообщения (до 100) |
| `!помощь` | — | список команд |

Нельзя наказать того, у кого роль не ниже твоей. Каждое действие пишется в **#модерация**.
Перед баном/киком/варном бот пишет нарушителю в личку причину (если личка открыта).

**Жалобы (тикеты):** в **#жалобы** бот держит кнопку «Подать жалобу» → форма (ник нарушителя, что случилось) →
приватный канал `жалоба-0001` (видят автор и команда). «Закрыть жалобу» (автор или команда) — переписка
сохраняется файлом в #модерация, канал удаляется через 10 секунд.

**Запуск:**
1. Discord Developer Portal → бот → Privileged Gateway Intents → **Message Content Intent** включён.
2. Права роли бота: Банить, Выгонять, Управлять участниками, Управлять сообщениями, Управлять каналами,
   Просматривать каналы, Отправлять сообщения, Читать историю, Прикреплять файлы. Роль бота — выше ролей команды.
3. `npm install` в этой папке, затем создать файл `.env` со строкой `DISCORD_TOKEN=...` (в git не попадает).
4. `node bot.js`. На VPS — сервис `systemd/mc-discordbot.service`.

Настройки — `config.json` (префикс, названия каналов и ролей команды). Предупреждения и номера жалоб — `state.json`.
Тесты логики: `node --test lib.test.js`.
