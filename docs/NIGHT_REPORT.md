## Что нашлось ночью (и уже исправлено)

- **Ошибка в BeezzAuth:** «Это я», нажатое после того как игра перестала ждать, не запоминалось — исправлено, есть тест.
- **Дыра в BeezzAuth:** код привязки можно было подбирать перебором — теперь после 5 неверных кодов аккаунт в мессенджере ставится на паузу на 15 минут.
- **Эмодзи в игре не рисуются** (шрифт Minecraft): подсказка с 💡 приходила квадратами — убрал эмодзи из игровых текстов.
- **В 26.x переименовали правила игры:** `playersSleepingPercentage` → `players_sleeping_percentage` — исправлено в сборке.
- **Антибот Sonar** отсекает любых ботов, даже «притворяющихся» клиентом → на боевом сервере нагрузочные тесты придётся гонять в обход Sonar.

## Что нужно от тебя

1. **Посмотреть и слить** `night/integration` (или ветки по одной).
2. **Выбрать дизайн сайта:** открой `site/designs.html` (локально: `python site/server.py`, потом http://localhost:8080/designs.html).
3. **Создать ботов** и вписать токены **на сервере** в `plugins/beezzauth/config.yml` (в чат не присылать):
   - Telegram: @BotFather → `/newbot`;
   - ВК: сообщество → Управление → Работа с API → ключ доступа (сообщения), включить Long Poll (входящее сообщение, действие с сообщением);
   - Discord: Developer Portal → New Application → Bot → токен, добавить бота на наш Discord-сервер.
4. **Домен** и **VPS** (AlphaVPS R6G) → `sudo DOMAIN=… EMAIL=… BEDROCK=1 ./setup.sh`.
5. **Проверить вход с телефона**, когда будет VPS с Geyser.
6. Вписать реальные ссылки на соцсети в `site/config.js` и в `plugins/BeezzCore/config.yml`.
