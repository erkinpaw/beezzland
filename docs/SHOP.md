# Донат

## Что продаём

| Товар | Сайт (рубли, ЮMoney) | Игра (жужики, `/donate`) |
|---|---|---|
| Silver / Gold / Diamond на 90 дней | 199 / 399 / 699 ₽ | 2000 / 4500 / 8000 |
| Разбан | 299 ₽, дальше 599, 1199, 2399… | 3000, 6000, 12000… (на сайте: забаненный в игру не зайдёт) |

Купил ранг ещё раз — дни добавляются (`parent addtemp … accumulate`). Цена разбана удваивается
с каждым купленным разбаном и не сбрасывается вайпами. Жужики за деньги не продаются.

## Как устроено

- `site/shop.py` — каталог, заказы (`shop.db`), уведомления ЮMoney, выдача. Настройки — `shop.json`
  рядом с `sessions.json` (создаётся сам при первом запуске сайта), читается при каждом запросе.
- Выдача идёт через локальный API BeezzAuth на прокси: `/shop/grant` → `lpv user … parent addtemp`,
  `/shop/unban` → `libertybans unban`. Если прокси лежит — сайт повторяет раз в минуту.
- Разбан за жужики: сайт списывает их прямо в `zhuzhiki.db` BeezzDuels одним запросом (баланс не уходит в минус).
- `/donate` в игре — BeezzDuels (`Donate.java`), ранги и цены в его `config.yml` → `donate`.

## Подключить ЮMoney (делает владелец кошелька, сам)

1. В `shop.json` вписать `yoomoney.wallet` (номер кошелька) и `yoomoney.secret`.
2. Секрет берётся на yoomoney.ru → Настройки → «HTTP-уведомления»: туда же вписать адрес
   `https://beezzland.ru/api/shop/yoomoney` и поставить галочку «отправлять уведомления».
3. По желанию: `notify.bot_token` и `notify.chat_id` — сообщение в Telegram о каждой покупке.

Секрет и токен в чат не присылать. Пока кошелька нет, кнопки «Купить» на сайте выключены.

Если сумма оплаты не совпала с ценой, заказ получает статус `check` и ничего не выдаётся —
владельцу кошелька приходит сообщение, выдать можно руками.

## Проверено (тестовый сервер, без настоящих денег)

Разбан за жужики, удвоение цены, форма ЮMoney, подписанное уведомление → Diamond на 90 дней,
поддельная подпись отклоняется, повторное уведомление не выдаёт второй раз, недоплата → `check`,
`/donate` в игре (не хватает жужиков, подтверждение, списание, Gold на 90 дней).
